# flex (`-a flex`)

Flex proof-of-work, used by **Kylacoin (KCN)** and **Lyncoin (LCN)**. Live and
pool-validated.

A GhostRider sibling, but do not assume anything carries over from `algos/ghostrider`
or `algos/mike`. Four differences, all consensus-load-bearing:

| | ghostrider / mike | flex |
|---|---|---|
| keccak padding | 0x01 (legacy Keccak) | **0x06 (SHA-3)** for *every* keccak in the chain |
| selection seed | header bytes `[4,36)`, nonce-independent | **SHA3-512 of the whole 80-byte header**, a per-**nonce** chain |
| CN finalization | `extra[state[0] & 3]`, 4-set, skein-**256** | `extra[state[0] & 2]`, 3-set, skein-**512** (64 bytes) |
| after a CN round | zero the high 32 bytes | **never**, and a final SHA3-256 hashes all 64 |

Core pool: 14 algos, the x16 set minus **JH** and SHA-512, and **reindexed**: a gr core
index does not mean the same thing as a flex one from index 3 up. CN parameters (memory,
iterations, lite half-addressing) are byte-identical to ghostrider's; only the ending differs.

The chain runs **15** core rounds, not 14: the reference reads `coreOrder[14]` although
selection fills only `0..13`, so slot 14 stays zero and the fifteenth core round is
**always blake512**. Pool-accepted vectors confirm this is consensus.

Difficulty: `opt_target_factor` stays **1.0**; flex does **not** share ghostrider's 2^16
factor. Merkle root: **sha3d** over the coinbase, then sha256d per branch.

## Layout

| File | Role |
|---|---|
| `flex.h` | core/CN enums, `FLEX_CORE_CHAIN_LEN`, and the CPU-reference API |
| `flex_hash.cpp` | CPU reference: SHA-3 helpers, order derivation, core/CN dispatch, the chain, the self-test. Pulls in `sph/` and the CryptoNight CPU cores and **nothing else** |
| `flex_kat.h` | **generated**; see below |
| `flex.cu` | GPU driver: nonce pre-filter, per-nonce pipeline, startup gate and guards, candidate screen |

The CryptoNight cores are shared with ghostrider: `cryptonight-cpu.cpp`'s
`cryptonight_v1_hash_ctx` takes a `flex_final` flag that selects the finalization and
nothing else, so there is **one** copy of the consensus loop, not two. Editing that file
affects ghostrider and mike as well.

Note: `sph_sha3d.h` (0x06) and `sph_keccak.h` (0x01) share the include guard
`SPH_KECCAK_H__`. Whichever is included first wins and the other silently becomes a
no-op. `flex_hash.cpp` includes **only** sha3d.

## Correctness gates

`flex_kat.h` carries two independent sources:

1. The **end-to-end consensus vector**: an 80-byte header and the digest a live
   Flex/Kylacoin pool **accepted**, parsed out of the CPU reference.
2. **SHA-3 vectors generated by Python `hashlib`**, an implementation entirely separate
   from our `sph` copy, which is what actually catches the 0x01-vs-0x06 trap. The legacy
   Keccak digests of the same messages are baked in too, so a padding mistake reports
   *"you produced the legacy Keccak digest"* by name instead of an anonymous mismatch.

The vector's derived chain puts **2 of 3 CN rounds on the blake branch and 1 on
skein-512**, so one header exercises both finalization branches and the in-place aliasing.

At GPU startup a fail-closed gate checks the pool-accepted vector on the device, a
negative control (nonce + 1 must differ) and a few lanes of the filtered path against
the CPU reference.

## Diagnostics

| Env var | Effect |
|---|---|
| `FLEX_GUARD=1` | add the full startup guards (wider chain, filtered path); `FLEX_GUARD_WIDTH` adds width invariance, `FLEX_GUARD_LANES` widens them |
| `FLEX_GATE_FAULT=1..4` | corrupt one digest in a gate leg (KAT, negative, filtered, `-D` differential) to prove it fires |
| `FLEX_DIFF_LANES` | lanes re-hashed on the CPU per job by the `-D` differential (default 16) |
| `FLEX_VERIFY=1` | screen audit (plain path only; reported unavailable under the nonce filter) |
| `FLEX_NONCE_FILTER=0` | take the plain path instead of the nonce pre-filter |
| `FLEX_CN_SERIAL=1` | run the CN variant groups one after another instead of concurrently |
| `FLEX_PROFILE=1` | log per-phase and per-CN-group timings |
| `FLEX_BENCH_TARGET` | override the relaxed `--benchmark` screen target |
